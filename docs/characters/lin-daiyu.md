# 林黛玉

## 我对她的理解

在这里自由地写你对黛玉的理解。

## 我最喜欢她的地方

- 真性情，她从不伪装，喜怒哀乐都发自内心，活得坦荡
- 坚守自我，宁愿孤独地坚守“质本洁来还洁去”
- 才华横溢
- 外柔内刚，寄人篱下但是很坚强

## 我不希望网站把她表现成

不希望只把她表现成爱哭、体弱和多愁善感的人。

## 我最想加入的生平情节

- 初入贾府
- 黛玉葬花
- 诗社夺魁

## 我最想收录的诗词

- 《葬花吟》
- 《秋窗风雨夕》
- 《咏菊》
- 《问菊》
- 《菊梦》

## 我希望她给人的第一感觉

第一眼给人觉得柔弱的让人心疼，但是她很清醒，比谁都有骨气，比谁都锋利

## 视觉设想

- 代表颜色：红色（绛色）
- 代表植物：水芙蓉和木芙蓉兼有
- 服饰感觉：白、蓝、粉红为主，核心纹样是竹叶、梅花、桃花、荷花、木芙蓉、兰花、忍冬纹；形制以宋、明两朝为基础，融入清代细节特征——交领袄、马面裙、披帛、斗篷为主，领型有交领右衽、圆领、立领三种；面料以轻盈透气为主——软烟罗、蝉翼纱、羽缎，强调下垂感和飘逸感
- 居所氛围：潇湘馆的氛围，是大观园里最幽静的一处院落，后院梨花有芭蕉错落，整体主色是绿色，清冷里透出一点娇柔
- 其他想法：暂时没有
