# 诗词收录计划

## 林黛玉

### 《葬花吟》
-是否必须收录：是
-最喜欢的诗句：“质本洁来还洁去，强于污淖陷渠沟。” / “侬今葬花人笑痴，他年葬侬知是谁？”
-喜欢的原因：这是黛玉生命底色的绝唱。她并非单纯地为落花伤感，而是在借落花自喻，表达在压抑环境中对高洁人格的宁死坚守，以及对自身命运无法自主的绝望预感。有一种超越世俗的孤勇与清醒。
-对应的人生阶段：大观园青春鼎盛却内部矛盾初显的时期，也是她深感寄人篱下、对未来最为迷茫的时期。
-希望搭配的画面：暮春时节，落红成阵。黛玉身披素衣，肩扛花锄，手持花囊，在冷月或细雨中独自于沁芳闸畔掩埋落花。画面里只有她与天地、与落花，无需他人旁观。
-希望搭配的声音：凄清的笛声远播，夹杂着风吹竹叶的沙沙声，以及黛玉压抑的低泣或叹息，背景音可以有一两声空灵的鸟鸣，衬托出极致的孤独。
-备注：切勿将其塑造成简单的“打情骂俏”或“无理取闹”。核心是“孤高”与“对生命消逝的悲悯”，是极具哲学意味的存在主义悲叹。

### 《秋窗风雨夕》
-是否必须收录：是
-最喜欢的诗句：“秋花惨淡秋草黄，耿耿秋灯秋夜长。已觉秋窗秋不尽，那堪风雨助凄凉！”
-喜欢的原因：全诗连用十五个“秋”字，将凄凉感推向极致。这是黛玉病情加重、漂泊感与无力感最集中的体现。她已不再像《葬花吟》那样抗争，而是化作了一声沉痛的叹息，暗合了贾府由盛转衰的颓势。
-对应的人生阶段：贾府繁华将尽、诸芳流散的尾声。黛玉身体日渐沉疴，深知自己命如秋草，已经完全放弃了与命运搏击。
-希望搭配的画面：秋雨敲窗的冷夜，潇湘馆内烛影摇曳。黛玉半卧在病榻上，神色苍白而平静，目光越过窗棂望向雨夜，桌上摊着未写完的诗稿，灯芯渐渐枯竭。
-希望搭配的声音：淅沥的秋雨声、雨打芭蕉的沉闷声、漏壶的滴答声，以及偶尔一两声咳嗽，环境音应由清冷转向彻底的寂静。
-备注：与《葬花吟》形成对照（抗争与消逝）。这不仅是爱情受挫的苦楚，更是无依无靠的女性在封建大家族风雨飘摇中，对生命流逝的无力长叹。

### 《咏菊》
-是否必须收录：是
-最喜欢的诗句：“一从陶令评章后，千古高风说到今。”
-喜欢的原因：借咏菊自况，毫不掩饰地赞美孤标傲世、不随波逐流的高洁品格。在黛玉笔下，菊花不是玩物，而是她精神世界的知己与化身。
-对应的人生阶段：大观园诗社鼎盛时期（菊花诗会夺魁）。此时的她才华横溢，对生命与爱情仍抱有强烈的向往与自信。
-希望搭配的画面：秋高气爽的午后，潇湘馆内墨香弥漫。黛玉凭案挥毫，窗外的菊花开得凌霜傲雪。她的眼神专注、明亮，透着一种“舍我其谁”的才情与锋芒。
-希望搭配的声音：毛笔落纸的沙沙声，微风吹动竹帘的清脆碰撞声，以及偶尔的鸟鸣，展现一种静谧而充满创造力的氛围。
-备注：这是黛玉精神锋芒的高光时刻，不要把焦点放在她的“病弱”上，而要突出她作为杰出诗人的傲骨与生命力。

### 《问菊》
-是否必须收录：是
-最喜欢的诗句：“孤标傲世偕谁隐，一样花开为底迟？”
-喜欢的原因：这一问，问的不是花，而是命运，是知己。她渴望在世上找到与自己灵魂契合的同伴，却因不肯妥协于世俗而深感孤独。有一种强烈的内心独白感。
-对应的人生阶段：与贾府众人关系深化的时期，内心极其渴望理解与共鸣，却又时刻保持着高度的精神洁癖。
-希望搭配的画面：清冷的秋日，黛玉独自一人站在盛开的菊花丛前，微微仰起头，眼神中带着一丝痴迷与质问，像是在与天地万物对话。
-希望搭配的声音：风声略过花丛的萧瑟声，远处隐约传来的钟磬音（不具象指向男性，仅作为空间环境的点缀），以及她略带急促、饱含感情的念诗声。
-备注：她的“小性儿”很多时候来源于这种对精神世界的高要求。这是一首孤独者的自白。

### 《菊梦》
-是否必须收录：是
-最喜欢的诗句：“醒时幽怨同谁诉，衰草寒烟无限情。”
-喜欢的原因：从绚烂的梦境跌回残酷的现实，巨大的落差感透出浓重的幻灭感。这句诗不仅是写菊之梦醒，也是黛玉对自身爱情与生命终将逝去的悲凉预感。
-对应的人生阶段：大观园风雨欲来，晴雯被逐等事件发生后。黛玉深感周遭环境的冷酷，内心的安全感彻底崩塌。
-希望搭配的画面：冷月高悬，霜露凝重。黛玉从一场短暂的迷梦中惊醒，四周只有无边的衰草与寒烟。画面色调转为灰冷、迷茫。
-希望搭配的声音：极度安静的环境音，只有她的一声沉重叹息，以及风吹枯草的沙沙声，营造出一种繁华落尽后的凄清。
-备注：此处应体现一种宿命般的哀愁，并非为了爱情哭泣，而是对自我命运无力回天的沉痛认知。

## 薛宝钗
### 《临江仙·柳絮》
-是否必须收录：是
-最喜欢的诗句：“万缕千丝终不改，任他随聚随分。” / “好风凭借力，送我上青云。”
-喜欢的原因：与黛玉的悲情不同，宝钗的这首词一改柳絮的哀怨基调，翻出新意。她坦然接受聚散离合的命运，不怨天尤人；同时展现出一种不甘平庸的志向、一份洞明世事后的理智与豁达。这是她“藏愚守拙”外表下，掩藏不住的勃勃生机与对自身人生价值的主动追寻。
-对应的人生阶段：大观园诗社最繁荣的时期。她尚有闲暇与姐妹们诗词唱和，也对自己未来的命运有着清醒的认知与掌控感。
-希望搭配的画面：暮春时节，漫天柳絮如雪般飞舞。宝钗立于大观园高处的亭台或水边，面朝空旷的远方，神色从容自信。画面没有哀怨，只有一种与命运达成和解后的辽阔。
-希望搭配的声音：风声由和煦转向开阔，可以搭配清越的编钟声或空灵的古琴声，她念出“好风凭借力”时，有长风灌满衣袖的音响效果，体现出一种“送风上青云”的豪迈与大气。
-备注：切忌将她处理成“觊觎权利宝座的冷血野心家”。“青云”不是指嫁入高门，而是指她在精神层面上对自我实现的渴望。她的“随分”不是随波逐流，而是极其清醒地“看透而不道破”。

### 《咏白海棠》
-是否必须收录：是
-最喜欢的诗句：“珍重芳姿昼掩门，自携手瓮灌苔盆。” / “胭脂洗出秋阶影，冰雪招来露砌魂。”
-喜欢的原因：这是宝钗人格的完美投影。白海棠的素净、淡雅、自持，完全符合她“罕言寡语，人谓藏愚”的大家闺秀风范。她不需要俗艳的胭脂，只以冰雪为魂，传达出一种高洁、内敛、不需外界评判的自我珍重。
-对应的人生阶段：初入大观园，与众人结社作诗。此时她刚展现才华，但对周遭环境保持着礼貌而清醒的边界感。
-希望搭配的画面：清净的庭院，一株白海棠静静绽放。宝钗没有在赏花，而是手持水瓮，亲自为苔盆浇水，姿态从容，半新不旧的衣裳在微风中纹丝不乱。
-希望搭配的声音：水流缓缓浇入盆土的声音，轻柔温和，配以白海棠枝叶在微风中轻颤的细微声响，整体声音氛围极其干净、素雅、让人心静。
-备注：突出她“淡极始知花更艳”的审美与哲学。她不是没有色彩，而是主动洗尽铅华，选择了一种克制的智慧。

### 《忆菊》
-是否必须收录：是
-最喜欢的诗句：“空篱旧圃秋无迹，瘦月清霜梦有知。” / “念念心随归雁远，寥寥坐听晚砧痴。”
-喜欢的原因：这是宝钗少有的表露内心惆怅与凄冷之作。不同于平日的理智周全，这首诗展现了她对过往美好时光的追忆，以及对事物消逝的无可奈何。空篱、瘦月、清霜，营造出极度的清冷感。
-对应的人生阶段：贾府开始走下坡路，大观园内部的欢笑逐渐减少。宝钗虽然仍维持着体面，但内心敏锐地察觉到了繁华将尽的悲凉。
-希望搭配的画面：深秋时节，曾经繁盛的菊圃如今空空荡荡。宝钗独自坐在窗前，看着清冷的月光洒在霜地上。她的眼神不再是平日的圆融通透，而是流露出一种隐忍的落寞与怅然。
-希望搭配的声音：远处传来的捣衣声（晚砧），孤雁划过长空的哀鸣，以及秋风吹过空荡荡的院落产生的回音。声音要体现出一种距离感和寒意。
-备注：打破将宝钗视为“无情”的刻板印象。她的“冷”是因为看得太透，她的“无情”背后是对世事无常最深沉的悲悯和自我保护。
