# 她们未完的花园

一个关于《红楼梦》女性人物的交互式文学网站。

## 核心概念

用户进入一座由女性记忆组成的大观园，通过人物生平、诗词、关系与交互，重新认识林黛玉、薛宝钗等女性。

## 核心问题

如果不只通过宝玉、贾府和判词来看她们，她们会怎样讲述自己？

## 第一阶段

- 花园序章
- 林黛玉人物章节
- 薛宝钗人物章节
- 钗黛双镜
- 未完花园结尾

## 视觉方向

现代工笔、纸本长卷、克制的空间动画，避免古风游戏和卡牌风格。

## 计划采用的交互

- 手掌拨开雾气
- 手势展开人物生平长卷
- 捏合手指拾取诗笺
- 双手展开人物关系
- 鼠标、触屏和键盘替代操作

## 当前状态

项目构思与资料整理阶段，尚未开始开发。
